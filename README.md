# QoL

A Quality of Life mod for Hollow Knight: Silksong

## Features

- Saved Fleas Counter
- Fast Settings
  + Faster Menu
  + Instant Text
  + Faster Lifts
  + Instant Levers
- Bellway
  + Faster Travel Animations
  + Faster Bellway Station Buy
  + Bell Beast Always Awake
  + Bell Beast Always Ready At Your Location
  + Faster Beastling Call
- Ventrica
  + Faster Travel Animations
  + Faster Ventrica Station Buy
- NPC
  + Faster NPC Introduction
  + Faster Boss Introduction
- Cutscene
  + Skip Cutscenes
  + Skip Dream Cutscenes
  + Fully Skip Dream Scenes
  + Skip Weakness Scenes
  + Skip Tutorial Tool Msg
- Old Patch
  + Old Float Override
  + Cloakless Clawline
  + Old Volt Vessels
  + Bind Dash Refresh
  + Pimpillo Pogo
  + Old Scuttlebrace
  + Old Mist
  + Trobbio Skip
  + Lever Skips
  + Faydown Cloak Without Needolin
  + Old Putrified Ducts Planks
